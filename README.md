# ศูนย์ช่วยเหลือประชาชนทางกฎหมาย อบจ.สุพรรณบุรี

ซอร์สโค้ดเว็บไซต์ประชาชน ระบบ LINE OA แบบฟอร์มออนไลน์ และหลังบ้านเจ้าหน้าที่

## ดาวน์โหลดเวอร์ชันล่าสุด

[ดาวน์โหลด ZIP ล่าสุด](https://github.com/peoplelawcenter/suphan-legalaid-public/archive/refs/heads/master.zip)

ใช้ลิงก์เดิมได้ทุกครั้ง เมื่อผู้ดูแล push เวอร์ชันใหม่เข้า master ไฟล์ที่ดาวน์โหลดครั้งถัดไปจะเป็นเวอร์ชันใหม่ ดาวน์โหลดแล้วให้ผู้ดูแลเซิร์ฟเวอร์ติดตั้งอัปเดตตามคู่มือ

## ติดตั้งและตรวจสอบ

ระบบใช้ Node.js 24, Vercel Functions และ Supabase ปัจจุบันยังไม่มี production Node server หรือ Dockerfile สำหรับสั่งรันโดยตรงบนโฮสต์ทั่วไป โฮสต์ PHP อย่างเดียวจึงยังรัน API ชุดนี้ไม่ได้

อ่าน [คู่มือเซิร์ฟเวอร์](docs/SERVER-HOSTING.md) และ [คู่มือตั้งค่าระบบ](docs/SETUP-GUIDE.md) ก่อนติดตั้ง

```sh
npm ci
npm test
```

โฟลเดอร์ api/ คือ backend และการสร้างหน้าเว็บ โฟลเดอร์ public/ คือไฟล์สาธารณะ ส่วน vercel.json คือ routing, headers และงานตามเวลา

ใช้ schema และ migration ตามลำดับเลขในโฟลเดอร์หลัก ฐานที่ใช้งานอยู่ต้องตรวจ migration ที่รันแล้วและสำรองข้อมูลก่อน เวอร์ชันนี้มี migration-17 สำหรับสถิติการเข้าชม

กำหนด Environment Variables บน backend เช่น SUPABASE_URL, SUPABASE_SERVICE_KEY, SITE_URL และค่าของ LINE/อีเมล/OAuth ตามฟีเจอร์ที่ใช้ ชุดเผยแพร่ไม่มีรหัสผ่าน คีย์ระบบ ข้อมูลประชาชน หรือไฟล์หลักฐานจริง

## การใช้ภายใต้เว็บ อบจ.

เส้นทางปัจจุบันใช้จากรากโดเมน เช่น /api/ และ /assets/ หากใช้โฟลเดอร์ย่อย เช่น /peoplelawcenter/ ต้องปรับ routing, URL, cookies และ OAuth ก่อน ต้องมี HTTPS สำหรับการเข้าสู่ระบบจริง
